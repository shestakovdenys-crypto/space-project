# Моя тема: Дослідження глибокого космосу та екзопланет
Чому моя: Мене з дитинства захоплюють загадки Всесвіту, масштаб галактик та перспектива колонізації інших світів.
Гра: 2D-аркада про керування космічним шатлом, де потрібно облітати астероїдні пояси та збирати зразки палива на невідомих планетах.
Бот: Telegram-бот, який щодня надсилає космічне фото дня від NASA, попереджає про магнітні бурі та повідомляє про найближчі запуски ракет.
Сайт: Інтерактивна вебенциклопедія Сонячної системи з 3D-картами планет, цікавими фактами та симулятором гравітації.
Застосунок: Мобільний трекер нічного неба, який за допомогою камери допомагає знаходити сузір'я, супутники та МКС у реальному часі.
Що може бути складно: Реалізація реалістичної фізики орбітального руху та інтеграція великих масивів відкритих астрономічних даних.
